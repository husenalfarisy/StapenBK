2. Kunci dan hasil referensi per kasus

Nilai dihitung langsung dari dataset yang diregenerasi. Gunakan sebagai pemeriksaan jawaban, bukan pengganti output SPSS. Seluruh pengujian inferensial dua sisi pada α = 0,05.

Catatan metodologis

  • Data merupakan data sintetis untuk latihan. Hasil uji tidak boleh dilaporkan sebagai temuan penelitian nyata.
  • Dashboard menghitung statistik referensi secara lokal. P-value Wilcoxon dan Mann–Whitney menggunakan pendekatan normal dengan koreksi kontinuitas dan koreksi ties; pilihan Exact di SPSS dapat memberi hasil sedikit berbeda.
  • Untuk pemeriksaan normalitas formal, jalankan Shapiro–Wilk pada SPSS sesuai desain: per kelompok untuk kasus dua/tiga kelompok dan pada skor selisih untuk data berpasangan. Dashboard menampilkan deskriptif distribusi (skewness/kurtosis), bukan menggantikan Shapiro–Wilk.
  • Pada kasus dengan kelompok berbeda, hasil tidak otomatis membuktikan pengaruh kausal. Pada kasus hubungan, korelasi tidak membuktikan sebab-akibat.
  • File mahasiswa dan dosen menggunakan algoritma serta versi seed yang sama. Jika kode aplikasi diperbarui, sinkronkan versi keduanya sebelum praktikum.
