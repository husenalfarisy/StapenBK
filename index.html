Generator Dataset Individual

Gunakan NIM untuk membangkitkan data individual bagi tujuh kasus penelitian BK. Setiap kasus disajikan dalam bentuk narasi; Anda perlu menentukan sendiri metode analisis yang tepat berdasarkan tujuan penelitian, desain, dan karakteristik data.

ⓘPrivasi: NIM diproses di perangkat ini dan tidak dikirim ke server maupun dicantumkan dalam CSV. NIM yang sama pada versi generator ini akan menghasilkan dataset yang sama.

1. Identitas dan pembuatan dataset

NIM tidak perlu terdaftar pada daftar kelas. Masukkan NIM pribadi dengan benar agar data dapat dibuat ulang.

Catatan penggunaan

  • Semua data merupakan data sintetis untuk pembelajaran, bukan data responden nyata.
  • Setiap file CSV memuat nama variabel pada baris pertama dan dapat diimpor melalui menu impor data SPSS.
  • Periksa asumsi yang relevan. Jangan memilih prosedur hanya karena pernah digunakan pada kasus sebelumnya.
  • NIM yang sama menghasilkan data yang sama pada versi 2.0. Simpan kode dataset untuk keperluan komunikasi dengan dosen.
  • File aplikasi mahasiswa tidak memuat kunci metode analisis. Gunakan hanya file ini untuk dibagikan kepada mahasiswa.
